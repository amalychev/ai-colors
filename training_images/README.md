# 📁 Training Images

Поместите сюда изображения для обучения нейросети.

## Требования к изображениям:

### ✅ Подходящие изображения:
- **Веб-дизайны** - сайты, интерфейсы, лендинги
- **Логотипы и брендинг** - корпоративная айдентика  
- **Интерьеры** - красивые комнаты, мебель
- **Картины и арт** - произведения искусства
- **Fashion фотографии** - стильные образы
- **Природные фото** - закаты, пейзажи с хорошими цветами
- **Рекламные материалы** - постеры, баннеры

### ❌ Избегайте:
- Размытые/темные фотографии
- Изображения с одним доминирующим цветом
- Скриншоты с текстом
- Очень яркие/кислотные изображения

### 📊 Рекомендуемое количество:
- **Минимум**: 50-100 изображений
- **Оптимально**: 200-500 изображений  
- **Максимум**: 1000+ изображений

### 📝 Поддерживаемые форматы:
- `.jpg`, `.jpeg` - основной формат
- `.png` - с прозрачностью
- `.bmp` - растровые изображения
- `.gif` - анимированные (берется первый кадр)

## Использование:

```bash
# Обработка изображений
python main.py process training_images

# Обучение модели
python main.py train training_images --epochs 100
```
